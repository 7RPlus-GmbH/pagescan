Rules
- Colours: Ink #16181C, Paper #F7F6F2, Signal #DE4B2E, Graphite #7C7E84.
- Type: IBM Plex Sans Medium 500 at -2% tracking for the wordmark;
  IBM Plex Mono for code, labels, version numbers.
- Wordmark is always lowercase, never bold or italic.
- Clear space = one arm (14/64 of the mark) on all four sides.
- Minimum size 16px — use favicon.svg / favicon-16.png, not a scaled master.
- Two opposing corners only. Never four, never rotated, never stretched.
- Signal red: one accent per view, 24px+ text only (3.8:1 on paper).
- Copy svg/ icon/ banners/ into brand/ at the repo root, so paths read
  brand/banners/readme-header-light-1280x320.png. PyPI needs absolute raw URLs.
